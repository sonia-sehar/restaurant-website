
# The Velvet Spoon
## Website Architecture
- **Pages:** This website consists of 8 distinct sections acting as pages within a single-page architecture (Home, About Us, Menu, Specials, etc.).
- **Navigation:** Built using pure CSS hash links (#home, #about, etc.) for smooth scrolling, along with a CSS checkbox toggle.
- **CSS Styling:** Styled using pure CSS3 with a custom Rose Gold, Cream, and Soft Brown color palette, CSS Grid, Flexbox, and media queries.
